## Install

Extract the ZIP at the root of your SD card, insert the card, open **TubeHero** from your firmware's menu, and connect to Wi-Fi.

| Firmware | Folder on the SD card | Open from |
| --- | --- | --- |
| TrimUI stock | `Apps/UTubeHero` | Apps |
| NextUI, NX Redux | `Tools/tg5040/TubeHero.pak` (Smart Pro S: `tg5050`) | Tools |
| spruceOS, Miyoo stock | `App/TubeHero` | Apps |
| muOS | `MUOS/application/TubeHero` | Applications |
| Knulli | `roms/ports/tubehero` | Ports |
| Anbernic stock | `Roms/APPS/tubehero` | Apps |

During a video, press **Power** to turn the screen off while the audio keeps playing; press it again or any button to turn it back on. Turn this off in **Settings → Power turns screen off** to let Power sleep the handheld as usual.

## Updates

If you have v0.1.0, install the latest ZIP for your model once to get the updater. Starting with v0.2.0, TubeHero checks for stable releases whenever you open it. You can also select **Settings → Check for updates** to check again or see the result.

When an update is ready, close and reopen TubeHero to apply it. Your library and playback preferences carry over. If the update cannot open its first screen, TubeHero returns to the previous working version.
